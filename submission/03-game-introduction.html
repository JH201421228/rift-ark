GAME OVERVIEW

게임 개요

01 / 03

플레이어는 무너지는 세계를 떠도는 요새 방주(Ark)의 지휘관입니다. 우측 균열에서 밀려오는 적을 막고, 전투에서 얻은 골드로 동료와 방주를 성장시키며 100개 스테이지를 돌파합니다.

1. 정찰적 태그·보스 약점·권장 편성을 확인합니다.
2. 편성50종 중 역할과 상성을 맞춘 동료 6종을 고릅니다.
3. 전투소환·지휘관 이동·주문·각인 선택으로 레인을 지킵니다.
4. 재건골드로 동료·지휘관·방주 시설을 성장시킵니다.

지휘관이 전장에 있다

지휘관의 오라 안에서 지원 능력이 작동합니다. 전선으로 나가면 강해지지만 직접 공격받을 수 있어 위치 선정이 곧 위험 관리입니다.

편성이 답인 전투

장갑·결계·재생·비행 등 적 태그에 맞춰 물리·술식·신성 피해와 대공 능력을 조합합니다. 단순 전투력보다 상성이 먼저입니다.

매번 달라지는 빌드

웨이브 사이마다 세 각인 중 하나를 선택합니다. 같은 편성도 각인 조합에 따라 공격·방어·오라 운용 방식이 달라집니다.

HOW TO PLAY

게임 방법

02 / 03

목표

  • 좌측의 방주를 지키며 모든 웨이브를 격퇴합니다.
  • 호위·돌파 등 특수 모드는 화면에 표시된 목표를 달성합니다.
  • 일반 스테이지를 진행해 다음 월드와 난이도를 해제합니다.

전투 전

  • 출격 화면에서 적 태그와 위험 요소를 확인합니다.
  • 동료 50종 중 정확히 6종을 편성합니다.
  • 지휘관 주문 12종 중 4종을 장착합니다.

전투 조작

입력동작판단 포인트
동료 슬롯 탭 → 레인 탭마나를 사용해 선택한 레인에 동료를 소환막아야 할 적의 태그와 동료 역할을 맞춥니다.
전장 롱프레스·드래그지휘관을 목표 위치로 이동오라 범위와 지휘관 피격 위험을 함께 봅니다.
레인 영역 탭지휘관을 해당 레인으로 이동위험한 레인에 빠르게 합류합니다.
주문 슬롯 탭균열력을 소비해 장착 주문 발동레인형 주문은 지휘관이 있는 레인에 적용됩니다.
각인 카드 탭웨이브 사이 세 선택지 중 하나 획득현재 적 구성과 편성을 보완하는 효과를 고릅니다.

승리 조건

모든 웨이브를 격퇴하거나 해당 모드의 목표를 달성하면 승리합니다.

패배 조건

방주 HP가 0이 되거나 호위·돌파 모드의 제한 시간을 넘기면 패배합니다.

처음 플레이할 때: 타이틀에서 빈 슬롯을 선택한 뒤 방주 → 출격 → 1-1 순서로 이동합니다. 화면의 도움말에서 피아 표식, 적 태그, 지휘관 오라 규칙을 언제든 다시 볼 수 있습니다.

실제 실행 화면 · 보유 동료 중 6종을 고르는 편성 화면

설치·실행 방법과 제출 링크

03 / 03

Android APK로 실행

  1. 제출 저장소 루트의 riftark-20260807c.apk를 기기에 내려받습니다.
  2. Android의 “알 수 없는 앱 설치”를 이번 설치에 한해 허용합니다.
  3. APK를 설치하고 균열의 방주를 실행합니다.
  4. 가로 화면으로 전환된 뒤 빈 저장 슬롯을 선택합니다.

지원 기준: Android 6.0(API 23) 이상 · 가로 화면 전용

소스에서 웹 실행

git clone https://github.com/JH201421228/rift-ark.git cd rift-ark/FE npm install npm run dev

터미널에 표시되는 주소(기본 http://localhost:5173)를 Chrome 계열 브라우저에서 엽니다. Node.js 22 기준으로 검증했습니다.
