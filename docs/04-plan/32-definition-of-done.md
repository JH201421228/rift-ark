## 3. 마일스톤 게이트

### 3.1 M0 — 기반 정비

- [ ] `npm run dev` 정상 기동
- [ ] 실기기에서 **가로 고정** (세로가 잠깐도 보이지 않음)
- [ ] 앱 종료 → 재실행 시 세이브 유지
- [ ] 백그라운드 → 복귀 정상
- [ ] 안드로이드 뒤로가기 정상 (모달 → 일시정지 → 종료확인)
- [ ] **콜드 스타트 ≤ 3초** (실기기 측정)
- [ ] `npm run assets:pack` 동작
- [ ] 게임 타이틀 확정
- [ ] 한글 폰트 적용 (DOM · Phaser 양쪽)

### 3.2 M1 — 수직 슬라이스 · **기계 검증으로 대체** (2026-08-03)

> 원안 1항은 "팀 외부 5명 플레이 테스트에서 '한 판 더 하고 싶다' ≥ 4/5" 였다.
> **테스터가 없으므로 이 게이트는 열리지 않는다** — 열리지 않는 게이트는 진행을 막기만 한다.
> 기계가 답할 수 있는 항목만 남긴다.

- [x] 결정론 테스트 통과 (B1)
- [x] 자동 플레이로 전투가 완주된다 (전 시드 · 헤드리스)
- [x] 연출이 `presenters.json` 데이터로 구동된다 (코드에 박히지 않음)
- [x] 전 씬 `shutdown()` 구현 · 구독 해제
- [x] React 렌더 < 700회 / 60초 전투 (10Hz 스로틀)
- [ ] 60fps 유지 — **실기기 계측 항목** (M5 로 이동)

> ⚠ **"재밌는가 · 살아 있어 보이는가 · 타격감이 있는가"는 기계가 답할 수 없다.**
> 이 판단은 **사용자가 직접 플레이하는 단계**로 미뤄졌다.
> 이 게이트는 "코어 루프가 **동작한다**"만 보증한다. **"재밌다"를 보증하지 않는다.**

### 3.3 M2 — 코어 완성

### 3.4 ★ M4 — 게임 완성 (현재 게이트)

**전부 이 저장소 안에서 재현 가능해야 한다.** 사람의 판단이 필요한 항목을 넣지 마라.

- [ ] `npm run lint` 경고 0
- [ ] `npm run test` 전항 통과
- [ ] `npm run data:validate` 경고 0
- [ ] `npm run economy` 통과 (무과금 파워 곡선 · 방치 비중 35–50%)
- [ ] `npm run balance:check` **하드 게이트 0 실패**
- [ ] `npm run build` 성공
- [ ] **전 화면 도달 가능** — 라우터에서 출발해 모든 화면에 진입 경로가 있다.
      만들었는데 아무도 갈 수 없는 화면 **0개** (병렬 개발에서 실제로 발생하는 결함이다)
- [ ] **신규 계정 → 마지막 스테이지 자동 플레이 완주** (중간 세이브 재적재 포함)

- [ ] 광고·분석은 **어댑터 경계까지** 완성 (실 SDK 없이 게임이 완결된다)

### 3.5 M5 — 마감 품질 (실기기)

- [ ] 실기기에서 가로 고정 시작 · 세로가 잠깐도 보이지 않음
- [ ] 강제 종료 후 세이브 유지 · 백그라운드 5분 복귀 정상 (오디오 재개 포함)
- [ ] 콜드 스타트 p50 ≤ 3초 / p95 ≤ 5초
- [ ] 중급 기기 평균 **FPS ≥ 50** · 저사양(RAM 2GB) **≥ 30**, 크래시 없음
- [ ] 손상된 세이브 · 미래 버전 세이브로 시작해도 앱이 죽지 않는다 (테스트로 고정)
- [ ] 연속 30전투 후 힙 증가 없음
- [ ] `dist/` ≤ 70MB

### 3.6 ~~M6 — 소프트런칭 / 글로벌~~ → **연기** (2026-08-03)

D1/D7/D30 · 결제 전환 · 크래시 프리 · 광고 참여율은 **실제 플레이어가 있어야 성립한다.**
PvP · 길드 · 원격 설정 · 현지화 · 스토어 자산도 함께 연기한다.

> **다음 단계는 지표가 아니라 사용자다.** 게임이 완성되면 사용자가 직접 플레이하며
> 하나씩 고친다. 그 피드백이 이 프로젝트의 첫 실사용 데이터다.
> 재개할 때는 `30-roadmap.md` 의 "연기된 항목" 표에서 시작한다.

## 5. 절대 타협하지 않는 항목

일정 압박이 아무리 심해도 이 목록은 게이트를 통과해야 한다.

| # | 항목 | 이유 |
|---|---|---|
| 1 | **확률 공개 컴플라이언스 + 롤 전량 로깅** | 법적 리스크. 입증책임이 사업자에게 있다. 서버가 없으므로 **클라이언트 시드 롤 + 재현 검증**이 그 자리를 대신한다 (P7-05) |
| 2 | **세이브 마이그레이션 테스트** | 세이브 파손 = 리뷰 폭탄 |
| 3 | **밸런스 하드 게이트 B1·B4·B6·B7** | 결정론 · 경제 벽 · 지배 전략 |
| 4 | ~~M1 외부 플레이 테스트~~ → **자동 플레이 완주 + 하드 게이트** | 테스터가 없다. 다만 **대체가 아니라 연기**다 — "재밌는가"는 사용자가 직접 플레이할 때 답한다 |
| 5 | **신규 도입 에셋의 출처 기록** | 기존 에셋은 자유 사용이지만 새로 들어오는 것은 다르다 |
| 6 | 콜드 스타트 실측 · 저사양 크래시 0 | **M5(실기기)로 이동.** 기기가 연결되면 즉시 잰다 |

> ★ 4번을 지운 것이 아니라 **옮겼다.** 이 목록의 원래 취지("재미 없는 게임에 8개월을
> 더 쓰지 않기")는 여전히 유효하다. 다만 그 판단을 **완성 이후 사용자 플레이**로 옮겼고,
> 그때까지는 "동작한다"만 보증한다. 이 구분을 흐리면 검증하지 않은 것을 검증했다고 믿게 된다.
| 8 | **전면 광고 0 / 강제 광고 0** | 약탈적 인식 = 트럭시위 · 리뷰 폭탄 |
