### 0-0.2 그러므로 이 문서의 규칙 다섯

| # | 규칙 | 왜 |
|---|---|---|
| ① | **카피에 "광고 없음 · 무광고 · 광고 제거 · 광고 0"을 쓰지 않는다** | `ads.json:enabled` 가 지금 `false` 라 1.0 시점에는 사실이더라도 쓰지 않는다. 1.1 에서 지워야 하고 **지운 것을 플레이어가 알아채고 리뷰에 쓴다** (`56 §8` 1단계가 같은 결론이다) |
| ② | **Play 리스팅에 "광고 포함" 배지가 뜬다** | 앱 콘텐츠 → 광고 = 예 로 답하는 순간이다 (`56 §4.1`). **배지와 카피가 어긋나면 플레이어는 카피 쪽을 거짓말로 읽는다** — 한국 스토어에서 특히 눈에 띈다 |

| ④ | **카피에 보상 배수를 숫자로 적지 않는다** | 배수는 `ads.json:rewardMult` 에서 오고 경제 게이트에 따라 움직인다 (`56 §6.3`). 카피에 박으면 **같은 사실이 두 곳에 적혀 갈라진다** — 이 저장소의 단일 실패 유형 |
| ⑤ | **광고를 켜는 릴리스의 제출 직전에 8번 장을 다시 찍는다** | 재촬영 대장 `57` **S-03** 이 그 항목이다 |

> ★ 지금 캡처하면 **광고 버튼은 화면에 없다** — `ads.json:enabled === false` 면 버튼
> 자체가 그려지지 않기 때문이다. 그리고 §3.2 의 장면 8개에는 결과 화면이 없다.
> 즉 **현재 스크린샷 자체는 광고 때문에 다시 찍을 필요가 없고, 바꿔야 하는 것은 카피뿐이다.**

## 0. 가장 중요한 원칙 — 스크린샷을 생성하지 않는다

> ★★★ **스토어 스크린샷의 본체는 반드시 "실제로 돌아가는 게임 화면 캡처"여야 한다.**
> 그 위에 카피와 프레임을 얹는 것까지는 허용된다. **그림으로 그린 가짜 화면을
> 스크린샷으로 내면 App Store 가이드라인 2.3.x(정확한 메타데이터)로 반려된다.**
> Google Play 도 같은 취지의 정책을 갖고 있다.

그래서 이 문서는 이미지를 **두 갈래**로 나눈다.

| 갈래 | 무엇 | 만드는 법 | 지금 상태 |
|---|---|---|---|
| **A. 생성해도 되는 것** | 앱 아이콘 · 스플래시 · 로고 · 피처 그래픽 | **코드로 렌더**(§2.0) 또는 이미지 모델 프롬프트(§2) | ✅ **이미 있다** |
| **B. 반드시 캡처해야 하는 것** | 스토어 스크린샷 | **실제 게임 캡처 → 합성** (§3) | ❌ **기존 32장은 가짜 · 폐기** |

**둘 다 Codex 가 한다.** A 는 §2.0 의 렌더 스크립트 지시서, B 는 §3.5 의 폐기·교체
지시서다. **이미지 모델도, 사람이 먼저 만들어 둘 것도 필요 없다.**
현재 인벤토리와 그 판정은 **§0-A** 에 있다 — 그것부터 읽는다.

## 1. 모든 프롬프트 앞에 붙이는 공통 스타일 블록

> **이 블록을 매번 통째로 복사해 프롬프트 맨 앞에 붙인다.** 빼먹으면 스타일이 흔들린다.

```

게임: 가로형 모바일 레인 디펜스. 팔라독 · 카툰워즈 계보.
아트: HD 픽셀아트. 레트로 향수가 아니라 "의도적인 현대적 선택".
톤: 어두운 세계 + 부조리한 병력. 배경과 UI는 진지하게, 유닛만 웃기다.

색:
  배경 기조   #0f0f1e  (거의 검정에 가까운 남보라)
  금색 액센트 #F2B33D  (재화 · 로고 · 강조)
  보라 액센트 #B45AD6  (균열 · 마법 · 위협)
  하늘색      아군 표식
  붉은색      적 표식

픽셀 규칙:
  - 안티앨리어싱 금지. 모든 픽셀은 온전한 색. 반투명 픽셀은 알파 0 또는 255
  - 그라디언트는 디더링으로 표현한다. 부드러운 블러 그라디언트 금지
  - 팔레트 제한: 레이어당 16색 이하 권장, 최대 32색
  - 아웃라인은 1px 단색. 유닛에만 넣고 배경 오브젝트에는 넣지 않는다
  - 배경은 유닛보다 항상 어둡고 채도가 낮다 (배경 명도 15–50% / 유닛 50–90%)

금지:
  - 실사 텍스처, 3D 렌더, 벡터풍 플랫 일러스트
  - 부드러운 에어브러시 그라디언트
  - 워터마크, 서명, 랜덤 문자열
  - 애플/구글 기기 프레임 (스토어가 거부한다)
  - 실존 게임의 캐릭터나 로고를 닮은 요소

출력: PNG-32 (RGBA), sRGB, 무손실, 메타데이터 제거
```

> `taskkill //F //IM chrome.exe //T` 와 `netstat -ano | grep :5199` 로 찾은 PID 를
> `taskkill //F //PID` 한다. 안 죽이면 다음 실행에서 포트가 막힌다.

#### ② ★★ 반드시 **dev 빌드**로 캡처한다

장면을 세우려면 상태를 주입해야 하는데, 그 손잡이는 **개발 빌드에만 있다.**

| 전역 핸들 | 무엇 | 어디서 노출 |
|---|---|---|
| `globalThis.__store` | zustand 스토어 (진행도 · 골드 · 장착 주입) | `store/index.js` |
| `globalThis.__battle` | `BattleScene` (배속 · 시뮬 상태) | `scenes/BattleScene.js` — `import.meta.env.DEV` 안 |
| `globalThis.__gm` · `__game` | GameManager · Phaser 게임 | |

> **`npm run check:prod` 이 이 네 개가 프로덕션 번들에 없음을 강제한다.**
> 그러니 `npm run build` 결과물로는 장면을 세울 수 없다 — **`npm run dev` 로 띄운다.**
> 이것은 결함이 아니라 설계다. 스토어에 나가는 빌드에 디버그 손잡이가 있으면 안 된다.

#### ③ ★★★ 캡처 해상도 — 게임의 뷰포트 규칙이 정한다

`game/viewport.js` 의 규칙은 한 줄이다:

```js
zoom = Math.min(화면높이 / 720, 화면너비 / 1280)
```

**여기서 나오는 결론이 캡처 규격을 전부 결정한다.**

| CSS 뷰포트 | zoom | 판정 |
|---|---|---|
| **1280 × 720** | **1** | ✅ 디자인 해상도 그대로. 기준 |
| **1564 × 720** (21.7:9) | **1** | ✅ 높이가 720 이면 가로만 열린다 — 레터박스 없이 **더 넓게 보인다** |
| 1920 × 1080 | 1.5 | ❌ **비정수 줌** — 픽셀아트가 고르지 않게 늘어난다 |
| 956 × 440 | 0.611 | ❌ 디자인 해상도 **아래로** 줄어든다 |

> ★ **규칙: CSS 뷰포트는 높이 720 · 너비 1280 이상으로 둔다.** 그러면 zoom 이 정확히
> 1 이고, 확대는 전부 `deviceScaleFactor` 가 맡는다.

#### ④ ★★ `deviceScaleFactor` 가 정수 확대를 공짜로 준다

실측: Phaser 캔버스의 **백스토어는 언제나 CSS 픽셀과 같다** (`backing == css`, DSF 1·3
모두). 즉 캔버스는 CSS 크기로 그려지고, 브라우저가 DSF 배로 확대한다.
그리고 `index.css` 가 캔버스에 `image-rendering: pixelated` 를 걸어 두었으므로
**그 확대는 nearest 다.**

DSF 1 캡처를 nearest ×3 으로 올려 DSF 3 캡처와 대조한 결과:

```
다른 서브픽셀: 3.29%
```

나머지 96.7% 는 완전 일치한다. 다른 3.29% 는 **DOM 텍스트**다 — 벡터 폰트라 DSF 3 에서
실제로 더 높은 해상도로 다시 그려진다. 즉 **정수 DSF 캡처는 픽셀아트를 뭉개지 않으면서
글자만 더 선명하게 만든다.** 스토어 이미지에 정확히 원하는 성질이다.

| 결정 | 값 |
|---|---|
| CSS 뷰포트 | **1280 × 720** (Play) · **1564 × 720** (App Store 21.7:9) |
| `deviceScaleFactor` | **3** (정수) |
| 캡처 원본 | 3840 × 2160 · 4692 × 2160 |

#### ⑤ ⚠ 남은 문제 — **1320 은 720 의 정수배가 아니다**

| 목표 | 원본에서 | 배율 | 판정 |
|---|---|---|---|
| Play **1920 × 1080** | 3840 × 2160 | **÷2** | ✅ 깨끗하다. 정수 확대 → 정수 축소 |
| App Store **2868 × 1320** | 4692 × 2160 | ÷1.636 | ⚠ 비정수 **축소** |

> **비정수 *축소*는 받아들인다. 비정수 *확대*는 받아들이지 않는다.**
> 축소는 정보를 버리는 연산이라 조금 부드러워질 뿐이지만, 1.5× nearest 확대는
> 어떤 픽셀은 1칸 어떤 픽셀은 2칸이 되어 **격자가 눈에 보이게 흔들린다.**
> 그래서 iOS 세트는 Play 세트보다 아주 약간 부드럽다 — **알려진 · 감수한 손해**다.
>
> `sharp` 에서: 확대는 `{ kernel: "nearest" }`, 축소는 기본(Lanczos)을 쓴다.
> **축소에 `nearest` 를 쓰면 1px 선이 통째로 사라진다.**

## 6. 검수 체크리스트

### 6.1 생성 이미지 (갈래 A)

- [ ] 아이콘을 **48×48 로 축소해도** 균열 모양이 읽힌다 ← **유일하게 중요한 시험** (§0-A.1)
- [ ] 스토어에 올린 아이콘이 **`FE/resources/` 판**이다 (`asset/generated/store/` 의 08-02 판이 아니다)
- [ ] `icon-1024.png` 에 **알파가 없다** (App Store) · `icon-512.png` 는 **32비트**다 (Play · §5.1)
- [ ] 아이콘에 **둥근 모서리를 직접 그리지 않았다**
- [ ] 아이콘에 **텍스트가 없다**
- [ ] 적응형 전경의 내용이 **중앙 66% 안**에 있다
- [ ] 스플래시 내용이 **중앙 1200×1200 안**에 있고 배경이 정확히 `#0f0f1e`
- [ ] 피처 그래픽에 **텍스트가 배너에 직접 그려져 있지 않다** (합성 로고는 좌측)
- [ ] 확대해서 봤을 때 **안티앨리어싱된 픽셀이 없다**
- [ ] 워터마크 · 서명 · 랜덤 문자열이 없다

### 6.2 스크린샷 (갈래 B)

- [ ] **전부 실제 게임 실행 화면 캡처다** ← 반려 사유 1순위
- [ ] 8장 모두 **가로**이고 규격 픽셀과 **정확히** 일치한다
- [ ] 확대는 **정수배 nearest**, 축소는 Lanczos 로 했다 (§3.0 ⑤)
- [ ] 캡처 뷰포트의 CSS 높이가 **720** 이었다 (게임 줌 1 · §3.0 ③)
- [ ] 카피가 게임과 **같은 글꼴**이다 (브라우저에서 얹었다 · §3.0 ⑦-A)
- [ ] 2868×1320 이 **잘리지 않고 좌우에 배경을 덧댄 형태**다
- [ ] FPS · 디버그 오버레이가 **한 장도 없다**
- [ ] 빈 화면 · 로딩 중 · 슬롯 미선택 화면이 **없다**
- [ ] 아군 하늘색 타원과 적 붉은 링이 **1번 장면에서 갈린다**
- [ ] 카피가 상단 6% · 하단 8% 를 침범하지 않는다
- [ ] 카피가 **실제로 있는 기능**만 말한다
- [ ] ★ **카피에 "광고 없음 · 무광고 · 광고 제거"가 한 번도 안 나온다** (§0-0)
- [ ] ★ **카피에 보상 배수 숫자("2배" · "×2")가 없다** (§0-0.2 ④)
- [ ] ★ **광고 크리에이티브 · UMP 동의 폼 · ATT 프롬프트가 찍힌 장이 없다** (§3.6)
- [ ] 투명 픽셀이 0개다

### 6.3 스토어 정책

- [ ] 기기 프레임(아이폰 목업 등)을 합성하지 않았다
- [ ] 다른 게임의 이름·캐릭터·로고를 닮은 요소가 없다
- [ ] "최고" "1위" 같은 검증 불가 주장이 없다
- [ ] 한국어판과 영어판 카피의 **내용이 같다**
- [ ] ★ **카피가 Play 의 "광고 포함" 배지와 어긋나지 않는다** (§0-0.2 ②)
- [ ] ★ 광고를 켜는 릴리스라면 **`57` S-03 의 8번 재촬영이 끝났다**

## 7. Codex 에게 시킬 때의 요령

이 저장소에서 반복해서 효과가 있었던 것들.

| # | |
|---|---|
| ① | **소유 파일과 건드리면 안 되는 파일을 명시한다.** 안 하면 공유 파일을 덮어쓴다 |
| ② | **포트를 지정한다.** `5173` 은 사용자가 쓴다 → 다른 포트를 준다 |
| ③ | **"끝나면 Chrome·dev 서버를 정리하라"** 를 넣는다 |
| ④ | **"못 한 것을 조용히 넘기지 말고 보고하라"** 를 넣는다. 실제로 절반이 미완을 남긴다 |
| ⑤ | **검수 스크립트를 같이 만들게 한다.** 눈으로 8장 × 2벌을 검사할 수 없다 |
| ⑥ | **검수 스크립트를 일부러 깨뜨려 실패를 보게 한다.** 통과만 보고 믿지 않는다 |
| ⑦ | **생성 이미지는 여러 장 뽑아 고른다.** 특히 아이콘은 5~10장 뽑고 48×48 시험으로 고른다 |
