# 55. 수익화 모델 결정 — 유료 vs 무료+보상형 광고

> ## ⚠ 이 판정은 같은 날 뒤집혔다 (2026-08-07)
>
> 아래 계산은 **유료 유지**를 권했다. 사용자는 그 계산을 읽은 뒤
> **"유료의 진입장벽 때문에 설치 인원이 급감할 것 같다"** 고 판단해
> **무료 + 보상형 광고**로 결정했다. 그 결정이 현재의 개발 방향이다.
>
> **이 문서를 지우지 않는 이유:** 계산은 여전히 참이고, 무엇을 감수하기로 했는지가
> 여기에 있다. 특히 §2(경제 붕괴)는 **결정으로 사라지지 않는 문제**이고,
> 실제로 구현에서 그것이 그대로 드러났다 — 실측 스윕 결과 "클리어 골드 2배"는
> 총수입을 **+110%** 밀어 게이트 11개 구간을 깨뜨렸고, 경제를 지키면서 줄 수 있는
> 최대치는 **×1.3 · 하루 1회(+19%)** 였다.
>
> | 무엇 | 어디 |
> |---|---|
> | 구현·절차·법무 | **[`56-admob-rewarded-integration.md`](56-admob-rewarded-integration.md)** |
> | 실측 스윕과 상한의 근거 | `56` §6 · `FE/src/game/data/ads.json:_rewardDoc` |
> | 기계 검증 | `npm run economy` (광고 켠 곡선을 함께 잰다) |
>
> **뒤집힘의 진짜 대가는 §3 의 표에 있다** — 되돌릴 수 없음(무료→유료 불가) ·
> 개인정보 수집 0 의 소멸 · 동의 흐름 · `No ads.` 카피의 상실.
> 그것들은 이제 **피할 수 없는 작업 목록**이다.

> **(2026-08-07 당시) 결론: 유료를 유지한다.** 이 게임에서 보상형 광고는 유료보다 **적게 벌면서**
> 설계·법무·되돌릴 수 없는 선택을 한꺼번에 지불한다.
>
> 이 문서는 그 판단의 **계산 과정**을 남긴다. 같은 질문이 다시 나왔을 때
> 감으로 다시 답하지 않기 위해서다. **결론을 뒤집으려면 §5 의 조건이 참이어야 한다.**

## 0. 30초 요약

```
설치 1건당 기대수익
  유료 $3.99  →  스토어 수수료 15% 차감  →  $3.39
  무료 + 보상형 광고                     →  $0.14 ~ $0.26

  ⇒ 광고가 이기려면 설치가 13~24배 더 나와야 한다.
     업계 관측치(무료:유료 다운로드 비)는 약 9~10배다.
```

그리고 위의 광고 수치는 **"클리어 골드 2배"라는 보상을 전제**한 값인데,
그 보상은 이 게임의 경제를 그 자리에서 무너뜨린다 (§2).
보상을 줄이면 시청률이 떨어져 광고 수익도 같이 떨어진다. **출구가 없다.**

## 1. 설치당 기대수익 — 계산

### 1.1 유료

| 항목 | 값 | 출처 |
|---|---|---|
| 가격 | $3.99 / ₩5,500 | 인디 프리미엄 관례 (`50 §8.1`) |
| 스토어 수수료 | 15% | Play 15% 프로그램 · Apple SBP (**신청해야 적용** — `53 §2`) |
| **설치당 순수익** | **$3.39** | |

### 1.2 무료 + 보상형 광고

광고 수익 = `설치 × 노출/설치 × eCPM ÷ 1000`. 세 항을 각각 이 게임의 실측으로 잡는다.

**① 노출 기회 (실측)**

```
스테이지 100개 · 목표 시간 합계 377분(6.3시간, 1회 완주)
경제 모델의 반복 가정 1.8회 → 총 플레이 11.3시간
⇒ 스테이지 클리어 = 광고 기회 약 180회
```

**② 설치당 실제 노출 — 이탈을 반영한 가중평균**

6시간짜리 캠페인을 끝까지 미는 사람은 소수다. 관대하게 잡아도:

| 이탈 지점 | 비중 | 클리어 수 | 시청률 40% 가정 | 기여 |
|---|---:|---:|---:|---:|
| 스테이지 5 이전 | 50% | 9 | 3.6 | 1.8 |
| 스테이지 25 부근 | 30% | 45 | 18 | 5.4 |
| 스테이지 60 부근 | 15% | 110 | 44 | 6.6 |
| 완주 | 5% | 180 | 72 | 3.6 |
| **가중평균** | | | | **≈ 17회** |

> 시청률 40% 는 **보상이 클 때**의 값이다. 골드 2배쯤 되어야 나온다.
> 그리고 그 보상이 §2 의 문제를 만든다.

**③ eCPM**

| 구간 | 값 | 비고 |
|---|---|---|
| 미국 보상형 (Android / iOS) | $16.49 / $19.63 | 2026 벤치마크 |
| 티어1(미·영·일) 보상형 | $15 ~ $40 | AppLovin 2025 퍼블리셔 기준 |
| 한국 | 티어1에 준함 | 게임 앱 기준 |
| **소규모 신규 앱 · 혼합 지역 실효값** | **$8 ~ $15** | 중개 하한에 붙는다. 헤드라인 수치는 규모가 있는 퍼블리셔의 값이다 |

**④ 결과**

```
17 노출 × $8 /1000 = $0.14
17 노출 × $15/1000 = $0.26
```

### 1.3 손익분기 설치 배수

```
$3.39 ÷ $0.14 = 24.2배
$3.39 ÷ $0.26 = 13.0배
```

**무료가 유료를 이기려면 다운로드가 13~24배 더 나와야 한다.**
업계에서 관측되는 무료:유료 다운로드 비는 **약 9~10배**다.
즉 **같은 정도의 발견 운을 가정하면 유료가 약 2배 앞선다.**

> ★ 이 계산은 광고 쪽에 유리하게 기울여 놓은 것이다 — 시청률 40%, 노출 17회,
> eCPM 상단 $15. 그 전제 중 하나라도 현실적으로 낮추면 격차는 더 벌어진다.

## 2. ★ 결정적 이유 — "골드 2배"는 이 게임의 경제를 무너뜨린다

계산보다 이쪽이 더 중요하다. `npm run economy` 실측:

```
골드원: 캠페인 클리어 1종          ← 골드 수도꼭지가 **하나뿐**이다

스테     필요골드      가용골드    배
  1        1,461        1,706   1.17
 20       65,697       84,455   1.29
 40      661,419      852,012   0.83   ← 가장 빡빡한 구간
 50    2,055,100    2,596,041   0.79   ←
 60    6,399,520    7,869,377   0.80   ←
 80   62,580,503   72,025,414   1.15
100  310,545,402  658,569,948   2.12
```

무과금 플레이어의 골드 여유는 **0.79 ~ 1.30배**다. 40–60 구간은 **의도적으로 모자라게**
잡혀 있다 — 그 구간이 이 게임의 벽이고, 그 벽은 **편성 퍼즐**이어야 한다
(`CLAUDE.md` 설계 결정 5 · 밸런스 게이트 B4).

**골드원이 클리어 하나뿐이므로, 클리어 골드 2배 = 총수입 정확히 2배다.**

```
0.79 → 1.58     0.83 → 1.66     1.30 → 2.60
```

그 순간 일어나는 일:

1. **40–60 스테이지의 벽이 사라진다.** 목표 파워의 1.6~2.6배로 들어가므로
   어떤 편성이든 통과한다. 100 스테이지의 `difficultyMult` 를 전부 다시 잡아야 한다.
2. **설계 결정 5 가 뒤집힌다.** "벽은 항상 편성 퍼즐이고 절대 경제 벽이 아니다"가
   **"광고를 봤는가"**가 된다. 이 게임이 팔라독 계보에서 지키려던 바로 그 지점이다.
3. **광고를 안 보는 사람이 정가를 치른다.** 무료 게임에서 광고를 거절하면 게임이
   2배 어려워진다 — 그것은 보상형이 아니라 **사실상 강제**다.
   (`CLAUDE.md` 하지 말 것: 전면 광고 · 강제 광고)

> **보상을 줄이면 되지 않는가?** 그러면 시청률 40% 가 유지되지 않는다.
> §1.2 의 노출 17회는 "볼 만한 보상"을 전제한 값이고, 보상을 반으로 줄이면
> 노출도 절반 이하로 떨어져 설치당 $0.07~0.13 이 된다 — 손익분기가 **26~48배**가 된다.
> **경제를 지키면 광고가 안 벌고, 광고를 벌게 하면 경제가 깨진다.**

## 3. 계산에 안 들어가는 비용 — 광고를 붙이면 함께 오는 것

| 항목 | 무슨 일이 생기는가 |
|---|---|
| **무료 → 유료 전환 불가** | Google Play 는 유료→무료만 허용한다 (`50 §8.1`). **무료로 내면 되돌릴 수 없다.** 반대로 유료로 내면 언제든 무료로 내릴 수 있다 — 옵션 가치가 전부 유료 쪽에 있다 |
| **개인정보 수집이 0 이 아니게 된다** | 광고 SDK = 광고 ID. `50 §7` · `53 §5` 의 Data safety · App Privacy 답변이 **전부 "없음"에서 바뀐다** |
| **동의 흐름이 생긴다** | EU: GDPR/UMP 동의 화면. iOS: ATT 프롬프트. 둘 다 첫 실행 UX 를 하나씩 더 늘린다 |
| **연령 등급이 올라갈 수 있다** | IARC 설문에 "광고 포함" 이 추가된다 (`53 §4`) |
| **스토어 카피의 최강 문구가 사라진다** | `54 §4` 의 `No ads. No IAP. No gacha.` — 영어권에서 이 게임의 가장 강한 차별점이다. `50 §4.3` 도 "없는 것" 문단을 판매 포인트로 쓴다 |
| **APK · 크래시 표면** | AdMob/AppLovin 은 Play Services 의존을 끌고 온다. 현재 32MB · 서버 0 · SDK 0 인 구성이 깨진다 |
| **네트워크 없는 곳에서의 동작** | 지금 이 게임은 **완전 오프라인**이다. 광고는 그 명제를 깬다 |

## 4. 그래서 무엇을 하는가

### 4.1 유지

- **유료로 출시한다.** 앱 생성 시점에 "유료"로 만든다 (`50 §4.5`).
- **광고 SDK 를 넣지 않는다.** `CLAUDE.md` 하지 말 것 목록에 **보상형 광고**를 명시했다.
- **"없는 것"을 1급 마케팅 자산으로 다룬다.** 스토어 리스팅·스크린샷 카피·긴 설명에
  `No ads. No IAP. No gacha.` 를 앞에 둔다 (`54 §4`).

### 4.2 가격 — 여기가 실제 손잡이다

수익성을 올리는 지렛대는 광고가 아니라 **가격 × 발견**이다.

| 전략 | 한국 | 글로벌 | 성격 |
|---|---|---|---|
| 낮게 | ₩2,500 | $1.99 | 다운로드 최대화. 리뷰 수가 빨리 쌓여 랭킹에 유리 |
| **기준(권장)** | **₩5,500** | **$3.99** | 인디 프리미엄의 중앙. 6시간 콘텐츠에 정당한 값 |
| 높게 | ₩9,900 | $6.99 | 리뷰가 안 쌓이면 그대로 묻힌다. 무명 1인 개발 첫 작에는 권하지 않는다 |

> 콘텐츠 분량은 실측 **6.3시간(1회 완주) · 11.3시간(반복 포함)** 이다.
> 이 숫자를 스토어 설명에 넣는다 — 유료 앱을 사는 사람이 가장 먼저 묻는 것이다.

### 4.3 되돌릴 수 있는 실험 순서

```
1. 유료로 출시 (₩5,500 / $3.99)
2. 4~8주 관찰 — 다운로드 · 리뷰 수 · 국가 분포
3. 정체하면 → 가격 인하 (₩2,500 / $1.99). 되돌릴 수 있다
4. 그래도 정체하면 → 무료 전환 + **1회성 "서포터" 결제**
   (광고가 아니다. §1 의 계산에서 광고는 설치당 $0.14~0.26 이고,
    한 번의 소액 결제는 전환율 2%만 되어도 $3.99 × 0.02 = $0.08 이면서
    **경제를 건드리지 않는다** — 순수 후원이므로 게임 규칙이 그대로다)
```

**3번과 4번은 유료로 시작해야만 열려 있는 선택지다.** 무료로 시작하면 2·3번이 없다.

## 5. 이 결론을 뒤집는 조건

아래 중 **하나라도** 참이 되면 다시 계산할 가치가 있다. 그전에는 아니다.

1. **설치가 유료 대비 20배 이상 나올 근거가 생겼다.**
   (스토어 피처링 확정 · 인플루언서 유통 확보 · 유의미한 UA 예산)
2. **복귀 이유가 게임 안에 생겼다.** 광고 수익은 **리텐션 사업**이고 이 게임은
   **완주 상품**이다. `34-scope-cut.md` 가 지운 일일 퀘스트 · 출석 · 방치 · 파견을
   되살리기로 한다면 그때는 계산이 달라진다 — 다만 그것은 이 프로젝트가
   2026-08-04 에 되돌린 바로 그 결정이다.
3. **경제를 건드리지 않는 광고 자리를 찾았다.** 예: 완주 후 해금되는 순수 장식
   (스킨·컬러). 지금 이 게임에는 그런 소모품이 **하나도 없다** — 만들어야 한다.

> 세 번째가 그나마 현실적이다. 다만 그것은 "광고를 붙인다"가 아니라
> **"광고를 붙일 수 있는 것을 먼저 만든다"** 이고, 순서가 반대다.

## 6. 만약 그래도 광고를 붙이기로 한다면

결론을 뒤집는 것은 사용자의 결정이다. 그때 필요한 것을 여기 남긴다 —
**이 절은 계획이 아니라 참고다.**

| 결정 | 권장 |
|---|---|
| 형식 | **보상형만.** 전면·배너는 `CLAUDE.md` 하지 말 것 |
| 네트워크 | Google AdMob (Capacitor 커뮤니티 플러그인 존재 · Play 심사 마찰 최소) |
| 붙일 자리 | 결과 화면 1곳만. 전투 중·화면 전환 중에는 절대 아니다 |
| 보상 | **골드 2배가 아니라 고정 소액**(예: 그 스테이지 보상의 +25%, 하루 3회 상한). `economy` 게이트를 다시 통과시켜야 한다 |
| 게이트 | `npm run economy` · `npm run balance:check` **재보정 필수**. 이 둘을 통과하지 못하는 보상은 넣지 않는다 |
| 법무 | UMP 동의 · ATT · Data safety/App Privacy 갱신 · 개인정보 처리방침 전면 재작성 (`50 §7` · `53 §5`) |
| 순서 | **한국 유료 출시 → 데이터 확인 → 그다음**. 첫 출시에 함께 넣지 않는다 |
