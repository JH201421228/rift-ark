## 1. 방주 (The Ark)

> ### ⚠ 2026-08-04 — 방주는 **홈 대시보드**다 (구현 기준)
>
> 아래 1.1 의 "단면도 요새"는 **구현되지 않았고, 앞으로도 만들지 않는다.**
> 뒤에 있던 Phaser `ArkScene` 은 비웠다(배경색만) — 사용자가 "이상한 배경"이라고
> 지적했고, 실제로 그것은 시설 카드 뒤에서 아무 정보도 주지 않는 장식이었다.
>
> 지금 방주 화면이 보여 주는 것은 **"내가 어디까지 왔고 다음은 어디인가"** 다:
> 다음 도전 카드(→ 출격) · 클리어/모은 별/쓴 별/동료 · 월드별 진행 바 ·
> 편성·동료 빠른 이동 · 시설 4종.
>
> ★ **여기 있는 숫자는 전부 파생값이다** — 홈이 새로 저장하는 상태는 하나도 없다.
> 진행도를 홈에 캐시하면 그 캐시가 언젠가 진짜와 갈라진다.
>
> 원래 방주는 **"받기"의 목록**이었다(방치 보상 · 파견 · 광고 2배 · 알림 권한).
> 그것들이 절삭으로 사라지자 화면이 비었고, 그 자리를 진행 상황이 채웠다.
> 상세: [`../04-plan/34-scope-cut.md`](../04-plan/34-scope-cut.md) 말미 §③

전투 사이의 홈 화면. 좌우 스크롤되는 단면도 형태의 요새로, 시설이 시각적으로 성장한다.

### 1.1 닫힌 선순환

```
전투 → 자원 획득 → 시설 재건 → 생존자 배치
   ↑                                    ↓
   └── 더 나은 전투 ← 지휘관·방치 강화 ──┘
```

**위키드 디펜스가 검증한 구조**를 그대로 따른다. 전투 밖 화면에 스탯 메뉴가 아닌 **서사적 존재 이유**를 부여하고, 전투 판타지와 경쟁하지 않는 두 번째 느린 판타지(집을 다시 짓기)를 만든다.

### 1.2 시설 6종

| 시설 | 레벨 상한 | 효과 | 해금 |
|---|---|---|---|
| **대장간** | 30 | 동료 장비 강화 해금 및 강화 상한 | 스테이지 8 |
| **성소** | 25 | 지휘관 HP·오라 반경·주문 슬롯 | 스테이지 12 |

## 2. 방치 보상

### 2.1 설계

| 항목 | 값 | 근거 |
|---|---|---|
| **상한 시간** | **8시간** (구독자 12시간) | `01-research/02` §1.3 |
| **보상률 기준** | **최고 클리어 스테이지** | 막혀 있어도 진전이 쌓이고, 진행이 모든 수동 소득의 마스터 배율이 됨 |
| **광고 2배** | 하루 **3회** | |
| **가시적 카운트다운** | 상시 HUD 표기 | 초과분 소멸이 징벌적으로 읽히지 않게 |
| **푸시 알림** | **6.5시간 시점 1회** | 상한 1.5시간 전 경고 |

```
idle_gold_per_hour  = base × 1.055^(highest_stage) × (1 + 관측소_보너스)
idle_stone_per_hour = floor(highest_stage / 5) × (1 + 관측소_보너스)
```

### 2.2 왜 8시간인가

12시간은 하루 2회 수거를, 24시간은 1회를 강제한다. **8시간은 하루 3회 수거(기상/점심/퇴근)** 를 유도하며 이는 목표 세션 수(5–7)와 잘 맞는다. 구독자 12시간은 "밤새 안 잃는다"는 명확한 가치 제안이 된다.

### 2.3 푸시 권한 요청 타이밍

**첫 방치 보상 수령 시점**에 요청한다 — *"상자가 가득 차면 알려드릴까요?"*
첫 실행 요청은 금지. 맥락 요청이 옵트인율을 대략 2배로 만든다 (`01-research/02` §1.2).

## 3. 동료 성장

### 3.1 3축 구조

| 축 | 재화 | 효과 | 상한 |
|---|---|---|---|
| **레벨** | 골드 | ATK/HP 선형 성장 | 훈련장 레벨 + 10 |
| **랭크** | 동료 파편 | **계단형 배율** + 능력 강화 | 5랭크 |
| **장비** | 강화석 | 슬롯 3개(무기/방어/장신구) | 대장간 레벨 |

```
Unit_ATK(lvl)   = base × 1.055^lvl
Upgrade_cost    = c_base × 1.12^lvl
Rank_multiplier = 1.0 / 1.35 / 1.85 / 2.5 / 3.4
```

**설계 원리 (재확인):** 연속 성장(레벨)은 적 성장보다 **약간 뒤처지게** 두고, 격차는 **이산 계단**(랭크업·신규 유닛 해금·장비 티어)으로 메운다. 파밍 → 압박 → 계단 상승 → 강함 체감 → 반복.

### 3.2 랭크업 = 규제 대상 강화 시스템

**랭크업에 랜덤 성공률을 두지 않는다.** 파편 N개를 모으면 100% 성공하는 결정론적 시스템으로 설계한다.

> **근거:** 한국 게임산업법은 **강화형 확률형 아이템도 규제 대상**이며, 소송특례로 입증책임이 사업자에게 전환됐다 (`01-research/02` §3.5). 강화에 확률이 없으면 이 리스크 전체가 사라진다.
> 확률형은 **가챠(캡슐형) 단 하나로 국한**하고, 그 하나만 완벽히 준수·로깅한다.

| 랭크 | 필요 파편 (누적) |
|---|---|
| ★1 → ★2 | 10 (10) |
| ★2 → ★3 | 25 (35) |
| ★3 → ★4 | 60 (95) |
| ★4 → ★5 | 120 (215) |

**중복 획득 처리:** 동일 동료 중복 → 파편으로 자동 전환. 5랭크 달성 후 중복 → **소유 효과 강화**(최대 5단) → 그마저 만렙이면 **강화석**으로 전환. **꽝 뽑기가 존재하지 않는다.**

### 3.3 장비

- 슬롯 3개, 등급 4단계
- **랜덤 옵션 없음.** 장비마다 고정 스탯 + 고정 효과
  → 강화형 규제 회피 + "장비 재굴림 지옥" 회피
- 강화는 +0 ~ +15, **100% 성공**, 비용만 상승
- 아이콘: `icons/Free - Raven Fantasy Icons` 2,192종에서 배정

| D30 | 스테이지 140, 동료 34종, 하드 모드 진입, 길드 활동 |
| D90 | 스테이지 200 완료, 동료 40+, 나이트메어, 엔드게임 루프 |

**무과금 기준선:** 위 페이싱은 **무과금 플레이어 기준**이다. 결제는 이 곡선을 **약 1.6배 가속**하되 도달 불가능한 지점을 만들지 않는다.

**젬 수급 목표:** 무과금이 **5–7일마다 10연** (`01-research/02` §6.1).
```
일일 무료 젬: 로그인 20 + 일일 퀘스트 30 + 업적/진행 평균 25 ≈ 75/일
10연 = 2,700젬 → 약 36일?  ✗ 너무 느리다
```
→ **10연 가격을 1,500젬**으로 낮추고 일일 무료 젬을 **평균 220/일**로 설정한다 (진행 보상·별 보상·이벤트 포함). 약 7일에 10연. 이것이 §6 페이싱을 성립시키는 실제 숫자이며 `14-economy-balance.md`에서 정산한다.
