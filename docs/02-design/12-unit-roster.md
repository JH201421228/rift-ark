## 0. 렌더 스케일 규약

에셋 원본 크기가 제각각이므로 **화면상 크기 계층**을 먼저 고정한다.

**디자인 해상도 1280×720 기준.** 배율 상수의 원본은 `src/game/config.js` 의 `SPRITE_SCALE`.

| 계층 | 원본 | 배율 | 화면 높이 | 픽셀 밀도 | 대상 |
|---|---|---|---|---|---|
| **소형 동료/적** | 16×16 | **×4** | 64px | 굵음 (1소스px = 4화면px) | `monsters/` 150종 |
| **대형 동료** | 32×32 | **×4** | 128px | 굵음 (동일) | `npcs/` 49종 |
| **지휘관** | 96×80 | ×2 | 160px | 고움 (1소스px = 2화면px) | `FREE_Adventurer` |
| **보스** | 80–250 | ×1~×4 (개별 지정) | **280–400px 목표** | 혼합 | `bosses/` |
| **이펙트** | 64×64 | ×2~×4 | 128–256px | 혼합 | `effect/` |
| **발사체** | 16×16 | ×4 | 64px | 굵음 | `projectile/` |

> **소형과 대형 동료는 픽셀 밀도가 완전히 동일하다** (16×16 ×4 와 32×32 ×4 모두 1소스px = 4화면px). 따라서 병력끼리는 아트 일관성이 완벽하다.
>
> **지휘관과 보스만 밀도가 다르다.** 이것은 **의도된 스케일 위계**로 규정한다 — 굵은 픽셀 = 소모성 병력, 고운 픽셀 = 이름 있는 존재. 모든 유닛에 동일한 1px 아웃라인 처리를 적용해 의도적 스타일라이제이션으로 읽히게 만든다 (`19-art-audio-direction.md` §3).

**보스별 배율** (목표 화면 높이 280–400px = 화면의 39–56%)

| 보스 | 원본 | 배율 | 화면 | 비고 |
|---|---|---|---|---|
| NightBorne | 80×80 | ×4 | 320×320 | |
| Bringer of Death | 140×93 | ×4 | 560×372 | 최종 보스. 폭이 화면의 44% |
| Undead Executioner | 100×100 | ×4 | 400×400 | |
| Mecha-stone Golem | 100×100 | ×4 | 400×400 | |
| FREE_Samurai | 96×96 | ×4 | 384×384 | |
| Necromancer | 160×128 | ×3 | 480×384 | ×3 은 밀도 예외 — 보스이므로 허용 |
| EVil Wizard 2 | 250×250 | **×1** | 250×250 | **1280×720 으로 올린 직접적 이유.** 640×360 에서는 ×1 이 화면 높이의 69% 를 먹어 선택지가 없었다 |

> **해상도를 1280×720 으로 정한 근거:** 보스 원본이 80–250px 로 편차가 크다. 640×360 에서는 큰 보스에 배율 선택지가 없어 화면을 가득 채우거나 픽셀 밀도를 깨야 했다. 1280×720 에서는 ×1~×4 범위가 전부 실용적이다.

### 1.1 등급 정책

**등급은 파워가 아니라 역할 복잡도와 유틸리티 폭이다.**
커먼 유닛이 특정 조합에서 레전더리보다 나은 상황이 **반드시** 존재해야 한다. 이것이 "토끼 스팸" 실패를 막는 최종 방어선이다.

| 등급 | 수 | 소환 코스트 | 특징 |
|---|---|---|---|
| **C 커먼** | 12 | 8–18 | 단일 기능, 저가, 스팸 가능 |
| **R 레어** | 14 | 20–35 | 조건부 강함, 명확한 카운터 역할 |
| **E 에픽** | 10 | 38–60 | 복합 유틸, 편성 축이 됨 |
| **L 레전더리** | 8 | 65–95 | 판을 바꾸는 능력. **높은 코스트로 스팸 불가** |

**밸런스 감사 규칙:** 헤드리스 시뮬레이터가 모든 등급의 유닛이 최소 1개 이상의 스테이지에서 "최적 편성"에 포함되는지 매 빌드마다 검증한다 (`03-tech/27`).

## 2. 소유 효과 (혁신 5)

편성하지 않아도 보유만으로 영구 적용되는 패시브. **중복 획득 시 5단계까지 강화.**

| 예시 | 소유 효과 |
|---|---|
| 꽥꽥 거위 | 모든 방벽 동료 HP +2% (중복당 +2%, 최대 +10%) |
| 꼬꼬댁 닭 | 모든 동료 첫 공격 속도 +3% |
| 예언자 | 각인 리롤 +1 (중복 3에서 +2) |
| 성십자 기사 | 신성 데미지 +4% |

**파워 크립 차단:** 역할 카테고리당 소유 효과 총합 상한 **+25%**. 상한 도달 후 중복은 **강화석**으로 자동 환전된다.

### 3.3 거대화 엘리트 (Giant Elite) 패턴

**16×16 스프라이트를 ×3~×5 스케일해 중간 보스로 사용한다.** 카툰워즈 3의 "거대" 접두 롤에서 차용.

| 효과 | 값 |
|---|---|
| 스케일 | ×3 (96px) / ×4 (128px) / ×5 (160px) |
| HP | ×8 / ×15 / ×25 |
| ATK | ×2.5 / ×3.5 / ×5 |
| 이동속도 | ×0.6 |
| `breachDamage` | 15 / 25 / 즉시 패배 |
| 시각 | 붉은 아웃라인 + 지면 균열 이펙트 + 등장 시 카메라 줌 |

> **이 패턴이 콘텐츠 레버리지의 핵심이다.** 보스 스프라이트 9체만으로 20개 이상의 보스 스테이지를 채울 수 있고, 신규 월드를 추가할 때 새 보스 아트 없이도 관문을 만들 수 있다.
