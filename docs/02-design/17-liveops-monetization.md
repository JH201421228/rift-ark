## 1. 지금 이 게임의 상태

| 항목 | 상태 |
|---|---|
| 인앱 결제 | **없다.** 결제 어댑터(`api/payments.js`)까지 삭제 |
| 가챠 | **없다.** 확률형 요소가 게임 전체에 하나도 없다 |
| 광고 | **없다.** 리워드 광고 어댑터 · 배치 정책 · 일일 상한 전부 삭제 |
| 배틀패스 | **없다** |
| 상점 | **없다** |
| 유료 재화 | **없다.** 재화는 골드 하나 |
| 일일 운영 (출석 · 퀘스트 · 시즌) | **없다** |
| 계측 · 퍼널 | **없다** |

동료는 **스테이지 클리어로 확정 지급**되고, 파워는 **골드**로만 오른다.

---

## 2. 왜 지웠는가

이 프로젝트는 "캐주얼로 획득하고 미드코어로 수익화"를 포지셔닝으로 잡고 있었다.
그 포지셔닝이 실제로 만든 것은 **게임 위에 얹힌 운영 층**이었고, 그 층이 게임의
라이트함을 먹었다:

- 홈 화면이 "오늘 받을 것"의 목록이 됐다.
- 탭이 아홉이 됐고 그중 다섯은 전투로 가는 길이 아니었다.
- 동료 하나를 키우는 축이 다섯이 됐고, 각 축이 다른 재화에 물려 있었다.

**팔라독 · 카툰워즈에는 그중 무엇도 없었다.** 그리고 이 저장소에는 그 층을
정당화할 수단 — 실플레이어 · 지표 · 스토어 계정 — 이 하나도 없다 (2026-08-03 방침).
검증할 수 없는 시스템을 유지하는 비용만 남아 있었다.

> 옛 §1 의 "수익화 원칙 8가지"(스테미나 없음 · 전면광고 0 · 편성 슬롯 미판매 …)는
> 전부 **"하지 않는다"의 목록**이었다. 그 목록은 이제 한 문장으로 줄었다:
> **아무것도 팔지 않는다.**

---

## 3. 규제 관점에서 무엇이 달라졌는가

이전 이 문서의 핵심 주장은 **"확률 공개는 나중에 붙이면 늦는다"** 였다.
한국 게임산업법(2024 개정)은 확률형 아이템의 확률 표시를 의무화했고 **입증책임을
사업자에게** 뒀으며, **강화형도 규제 대상**이다.

지금은 그 주장이 무의미해졌다 — **적용 대상이 존재하지 않는다.**

| 규제 항목 | 이 게임의 상태 |
|---|---|
| 확률형 아이템 확률 표시 | 확률형 아이템 **없음** |
| 강화형 확률 표시 | 강화 **없음** (레벨업 · 시설 전부 결정론) |
| 컴플리트 가챠 | **없음** |
| 미성년자 결제 보호 | 결제 **없음** |
| 광고 식별 표시 | 광고 **없음** |

> **이 상태를 지키는 것이 절대 규칙 6 이다.** 확률형을 하나라도 넣는 순간
> 위 표 전체가 되살아나고, 그것은 기능 하나가 아니라 **법적 표면 전체**를 다시 여는 일이다.

## 4. 되살린다면

되살리는 것 자체를 금지하지는 않는다. 다만 **순서가 있다.**

1. **먼저 게임이 재미있어야 한다.** 사용자가 100 스테이지를 직접 완주하고
   "여기가 비어 있다"고 말한 지점이 있어야 한다.
2. **그 지점에 맞는 것만 넣는다.** "F2P 게임에는 보통 이게 있으니까"는 이유가 아니다 —
   그 논리가 이 문서를 294줄로 만들었다.
3. **확률형은 마지막까지 고려하지 않는다.** 위 §3 의 표를 다시 여는 값이
   그 기능의 값보다 큰지부터 계산한다.

과거 설계안(가챠 천장 구조 · 배틀패스 예산 · 12주 캘린더)은 **이 저장소가 git 이 아니므로
이력에 남아 있지 않다.** 되살릴 일이 생기면 `01-research/02-market-retention.md` 의
BM 절부터 다시 시작하는 편이 정확하다 — 그것은 리서치이고, 리서치는 여전히 유효하다.
