## 1. 캠페인 구조

**10 월드 × 20 스테이지 = 200 스테이지 × 3 난이도 = 600 플레이 단위**

### 1.1 월드별 설계

각 월드는 **하나의 새로운 개념을 가르치고, 그 개념을 요구하는 보스로 끝난다.**

#### 구현됨 — 월드 1–5 (P6-02 · P6-03, 2026-08-03)

> **정본은 `FE/src/game/data/worlds.json` 이다.** 아래 표는 그것의 요약이며,
> 세력 배치가 원안(다음 절)과 다르다 — 에셋 팩 실물과 태그 도입 순서에 맞춰 바뀌었다.
> 가르치는 순서(기본 문법 → 원거리·속공·`WARDED`·`REGEN` → `CORRUPT`·2조건 →
> 방벽 해체 → 술식 반사)는 유지된다.

### 3.2 기억의 탑 (스테이지 40 해금) — 혁신 14

**주간 로테이션 로그라이트 던전.** 엔드게임 콘텐츠 엔진.

| 항목 | 값 |
|---|---|
| 층 수 | 무한 (기록 갱신형) |
| 각인 픽 | **12–18회** — 진짜 빌드가 완성됨 |
| 시도 | 주 3회 (구독자 5회) |
| 리셋 | 매주 월요일 05:00 KST |
| 보상 | 도달 층수 기준 강화석·젬·별, 주간 랭킹 |

**주간 규칙 — 반드시 능력을 *제거*하는 방향**

| 예시 규칙 | 효과 |
|---|---|
| 침묵의 주간 | 술사 역할 편성 불가 |
| 고립의 주간 | 오라 반경 50%, 각인 픽 2배 |
| 강철의 주간 | 전 적 `ARMORED` |
| 무중력의 주간 | 전 적 `FLYING` |
| 빈곤의 주간 | 마나 재생 60%, 소환 코스트 상승 없음 |
| 홀로의 주간 | 편성 슬롯 3개 |

> **감산적 제약이 가산적 버프보다 훨씬 더 새로운 플레이를 만든다.** PvZ의 밤/안개 스테이지가 가장 기억에 남는 이유가 이것이다. 규칙이 스탯 배율일 뿐이면 노가다 리스킨이 된다.

12종 규칙을 준비해 12주 로테이션 후 순환 + 시즌마다 2종 추가.

### 3.3 돌파 시험 (혁신 9) — 소탕권 대체

**소탕권을 판매하지 않는다.** 대신:

| 항목 | 값 |
|---|---|
| 조건 | 클리어한 스테이지 재도전, **적 스탯 ×1.5 + 거대화 엘리트 2체** |
| 성공 시 | 5 / 10 / 20 스테이지분 보상 즉시 획득 |
| 실패 시 | 소모 없음 (재도전 자유) |
| 해금 | 해당 월드 클리어 |

시간을 존중하되 **콘텐츠 보상**이지 페이월이 아니다.

### 3.4 비동기 PvP — 균열 각축전 (스테이지 60 해금)

| 항목 | 값 |

## 7. 콘텐츠 소비 속도 관리

| 위험 | 대응 |
|---|---|
| 상위 유저가 3일 만에 200 스테이지 소진 | 하드/나이트메어 + 기억의 탑 무한 + PvP 시즌 |
| 오토 배틀로 콘텐츠 급속 소모 | **오토는 클리어한 스테이지에서만** |
| 신규 콘텐츠 제작 속도 < 소비 속도 | 이벤트 템플릿 7종으로 리스킨 콘텐츠 생산 |
| D7 급락 ("다 봤다") | 기억의 탑 주간 규칙이 매주 새 플레이를 강제 |

**"D1이 높은데 D7이 급락"은 콘텐츠 부족이 아니라 *새로움 부족*의 신호다** (`01-research/01` §5.3 진단 지표). 기억의 탑이 이 진단의 처방이다.
