# 사용된 에셋 크레딧

> ⚠ **이 파일은 생성물이다. 직접 고치지 마라.**
> 단일 출처는 `FE/src/game/data/attributions.json` 이고, `npm run docs:attributions` 로 다시 만든다.
> 게임 내 **설정 > 라이선스** 화면도 같은 JSON 을 읽는다 (P7-15).
> 최종 갱신: 2026-08-03

> `FE/asset/` 의 모든 에셋은 자유롭게 사용 가능하다 (2026-08-02 확인, `docs/01-research/04-license-audit.md`).
> 크레딧이 의무가 아닌 팩도 전부 기재한다 — 비용이 0이고, 원작자에 대한 예의이며, 커뮤니티 인상에도 좋다.
